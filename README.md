# 📊 PowerBI Sales Performance Dashboard


## 🚀 Project Overview

An interactive **Sales Performance Dashboard built in Microsoft Power BI** designed to transform raw sales data into actionable business insights.

This project focuses on creating a professional BI solution that combines:

- Data modeling
- DAX calculations
- Interactive visualizations
- Drill-through analysis
- Customer segmentation
- Regional performance tracking
- Product profitability analysis
- Executive storytelling

The dashboard was designed with a strong emphasis on both **business intelligence and user experience**, creating a report that feels like a modern analytics product rather than a traditional dashboard.

---

# 🎯 Business Objective

The goal of this project was to build a centralized sales analytics solution that helps stakeholders answer key business questions:

- How is overall sales performance progressing?
- Which regions contribute the most revenue and profit?
- Which products drive business growth?
- Which customer segments are most valuable?
- Where are profitability opportunities and risks?
